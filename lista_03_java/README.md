# Lista 03 - Estrutura de Dados I

Soluções em Java para os exercícios de fixação da unidade curricular de Estrutura de Dados I do curso de Tecnologia em Análise e Desenvolvimento de Sistemas do IFTM - Campus Patrocínio.

## Questões

| Arquivo | Tema | Estratégia |
| --- | --- | --- |
| `Questao01.java` | Inserção ordenada em lista estática | Busca da posição e deslocamento à direita |
| `Questao02.java` | Remoção de elementos por valor | Compactação estável in-place |
| `Questao03.java` | Intercalação de listas estáticas ordenadas | Técnica de dois ponteiros em O(N + M) |
| `Questao04.java` | Partição de lista por pivô | Partição estável em três grupos |

## Requisitos

- Java Development Kit (JDK) 17 ou superior
- Terminal compatível com os comandos `javac` e `java`

## Compilação e execução

Cada questão é um programa independente.

```bash
javac Questao01.java
java Questao01
```

Substitua `Questao01` pelo número da questão desejada.
