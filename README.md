# Programming Practice: Logic, Arrays and Algorithms

Solutions for the first practical assignment of **Data Structures I** in the
Technology in Systems Analysis and Development program at IFTM - Campus
Patrocinio.

## Exercises

| File | Exercise | Approach |
| --- | --- | --- |
| `questao_01_two_sum.cpp` | Two Sum | Hash table for an `O(N)` search |
| `questao_02_remover_duplicatas.cpp` | Remove Duplicates | Two pointers and in-place updates |
| `questao_03_inverter_string.cpp` | Reverse String | In-place reversal |
| `questao_04_mover_zeros.cpp` | Move Zeroes | Stable in-place compaction |
| `questao_05_elemento_majoritario.cpp` | Majority Element | Boyer-Moore voting algorithm |
| `questao_06_mariana.cpp` | Ana, Viva a Mariana! | Arithmetic-series formula |
| `questao_07_datas_duvidosas.cpp` | Ambiguous Dates | Date validity and ambiguity check |

## Requirements

- A C++ compiler with C++17 support, such as GCC 9+ or Clang 10+
- A terminal (PowerShell, Command Prompt, Bash or a similar shell)

## Compile and run

Each exercise is an independent console program. Replace the file name below
with the exercise you want to run.

```bash
g++ -std=c++17 -Wall -Wextra -pedantic questao_01_two_sum.cpp -o questao_01
./questao_01
```

On Windows PowerShell, run the executable with:

```powershell
.\questao_01.exe
```

Then enter the values in the format described in the assignment. For example:

```text
4 9
2 7 11 15
```

Expected output:

```text
0 1
```
